# End-to-End Machine Learning Project

## Overview
This project demonstrates a complete machine learning workflow including data preprocessing, model training, evaluation, and prediction.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Model Training
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python main.py
```
